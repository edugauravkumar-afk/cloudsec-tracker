Operating rules

  1. Hands-on before video whenever possible: open the console, then watch the explanation.
  2. Never study a service without touching it. If a task says lab, it counts double.
  3. Every wrong practice question becomes one line in that week's notes. Re-read all notes before each exam.
  4. Book only on evidence (two consecutive ≥ 85%), not on calendar pressure. A failed AWS attempt costs the full fee and a 14-day wait.
  5. Destroy lab resources at the end of every session. Check the billing page every Sunday.
  6. Start applying for cloud-security roles the week you pass SCS-C03. Certifications get interviews; the portfolio repo gets offers.
  7. If you fall two weeks behind, cut scope from the phase — do not shift the exam. Speed of getting the first cert matters more than completeness.
